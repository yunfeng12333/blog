这篇写在出发之前。

十月底我们会去巴塞罗那和瓦伦西亚看学校。等回来再写，我大概率会不自觉地把结论合理化——人看到结果之后，很难诚实地复述自己原来的想法。所以我决定先把判断钉在这里，包括我现在最没把握的部分。

回来之后写第二篇，对照着看哪几条错了。

## 先说清楚，不是因为爱尔兰不好

跟人聊起要搬走，对方第一反应通常是「是不是孩子教育的问题」。

不是。

都柏林的教育对我们家完全够用。**我不是一个很卷的父母**——两个孩子现在读得好好的，我没有非要把他们送进哪个榜单的前几名。如果教育是唯一的变量，我们没有理由走。

食品和安全也是一流的。这两件事在移居讨论里经常被当成核心指标，爱尔兰在这两条上几乎挑不出毛病。住了七年，这个我愿意先说在前面。

所以下面这些离开的理由，都不是「这里不好」。

## 第一个理由是主动的：我们家的原则

我们家有一条原则：趁还能动，多过几种不同的生活，多待在几种不同的文化里。

这不是一句漂亮话，它有明确的代价——每搬一次家就要重新建立生活，孩子要重新交朋友，我要重新安排业务。愿意付这个代价，是因为我们认为「在一个地方稳定住三十年」和「在几个地方各住几年」是两种不同的人生，而我们选后者。

七年，差不多到了这个节点。

## 第二个理由：天气

爱尔兰最大的问题是天气。

先说句公道话：这两年因为全球变暖，这里的天气其实好了不少。

但问题从来不在某一个夏天。

温度本身不算低，都柏林的冬天很少到零下。难受的是**体感**——常年的阴雨加上风，温度计上的数字和身体的感受是两件事。

真正压人的是日照。冬天日照短到什么程度：**孩子早上去学校，天是黑的；下午放学，天还是黑的。** 他们一天里能见到自然光的时间，基本只剩课间。

还有一个数字可以说明这里的冬天有多长：**我们家一年要开十个月暖气。**

## 第三个理由：物价

第二大的问题是物价。

给一个具体的数字：**我们一家四口在都柏林，算上两个孩子的国际学校学费，一年大约九万欧元。**

这个数字里**不包含住房**——房子是自有的，没有房租，也没有贷款。

也就是说，九万欧元是在已经省掉一个家庭最大的一笔开支之后，还要花掉的钱。

所以这趟去西班牙，要验的核心问题只有一个：**同样的生活质量，在巴塞或瓦伦西亚一年要花多少。**

学费那部分我已经问到了报价，两个孩子一年从一万多欧到三万多欧不等，差着两三倍；但学费只是其中一块，其余的要到了才知道。

## 前面两条路是怎么断的

二〇一九年七月我们落地都柏林，到现在七年。离开的念头不是突然冒出来的，但真正开始找下一站，是从日本那条路开始的。

**日本**：走经营管理签，在大阪投了资本金，等签证。最后没等到。<!-- 补一两句：卡在哪一步？是审批本身，还是你中途判断这条路成本不对？这段别写成抱怨，写成「我当初对什么估计错了」 -->

**香港**：路径是我自己去读硕士拿学生签，配偶和孩子走受养人签，毕业后转 IANG。纸面上比日本干净——不用注资，不用维持实体公司，时间表也短。二〇二六年九月八号，我们放弃了这条路。

## 筛选条件没变过

三次改道，候选地换了三个，但筛选条件一直是这四条：

1. 两个孩子能进 IB 或纯英语学校
2. 我能远程管理现有的业务
3. 家庭整体成本不高于现在
4. 气候比爱尔兰好

这里有个区别值得说清楚：**前两条是底线，后两条才是目标。**

教育和业务不是我们要「改善」的东西，是不能退步的下限——都柏林已经做到了，新地方达不到就直接出局。真正要改善的是天气和成本，那才是我们动身的原因。

很多人把这两类条件混在一起排序，结果是为了一个更好的学校，接受了更差的生活。

## 这趟要验证的清单

去之前定死要采集什么，否则回来会发现关键信息当时没记。

**学校**

- [ ] 从可能住的区到学校的实测通勤时间——自己走一遍，早高峰，不看地图估算
- [ ] 两个孩子能不能进同一所（这是硬指标，不是加分项）
- [ ] 非母语学生第一年的语言支持怎么安排
- [ ] 学段衔接：小的那个升上去还在不在这所
- [ ] 学费之外的费用：注册费、校车、餐费、活动费
- [ ] 这两个年级**现在实际有几个位子**，不是「有没有位置」
- [ ] 家长构成：本地家庭和国际家庭的比例

**城市**

- [ ] 日常摩擦：超市、看病、办居留，各自多麻烦
- [ ] 通勤的体感，不是地图上的距离
- [ ] 周末无聊的下午能干什么
- [ ] 不会西语的日常成本；巴塞还要多算一层加泰语
- [ ] 气候的体感，不是气象数据

**街区**

- [ ] 到学校的真实路线，走一遍
- [ ] 这个租金带实际能看到什么房子
- [ ] 白天和晚上各走一次
- [ ] 噪音、停车、垃圾
